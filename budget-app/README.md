# 우리집 가계부 (MVP)

엑셀 가계부(수입 · 지출계획 · 지출 · 피벗 시트)를 옮긴 모바일 웹앱(PWA)입니다.
데이터는 **이 브라우저(localStorage)에만** 저장되고 외부로 전송되지 않습니다.

## 기능

| 화면 | 엑셀에서 하던 일 |
|---|---|
| 요약 | 실수입/실지출, 실수입−실지출, 예상 월말 잔액(남은 고정비·저축 차감), 계획 단계 적자 경고, 그룹별 진행률, 예산 초과 항목 |
| 지출 | `2026년 11월 지출` 표 입력. 큰 항목 → 작은 항목 연동, 주차 자동 계산(1–7일=1주차), 내용 자동완성(이전 분류·결제방법 채움), 수정/삭제, 필터 |
| 수입 | 수입 계획 + 실 수입 내역, 전월 잔액을 이월금으로 추가 |
| 예산 | 그룹·항목별 계획/실지출/차이, 전월 예산 복사, 십일조 계산 후 헌금 예산에 적용, 피드백 메모 |
| 리포트 | 항목×주차(`지출 합계` 피벗), 큰 항목×주차, 결제방법×큰 항목(`결제방법` 피벗), 항목별 순위, 최근 6개월 |
| 설정 | **엑셀(.xlsx) 가져오기**, JSON 백업/복원, 십일조 규칙, 분류·결제방법 관리 |

### 엑셀 가져오기
시트 이름이 아니라 머리글로 표를 찾으므로 매달 시트 이름이 바뀌어도 됩니다.
- 지출: `날짜 / 큰 항목 / 작은 항목 / 결제방법 / 내용 / 금액 / 비고`
- 실 수입: `날짜 / 내용 / 금액`, 수입 계획: `이번 달 수입 계획` 블록
- 지출 계획: `이번 달 ○○ 계획` 블록들, 분류: `지출 목록` 시트
- 금액은 원 단위로 반올림합니다 (예: 헌금 395,906.7 → 395,907).
- "해당 월 교체"를 켜면 같은 달을 다시 가져와도 중복되지 않습니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm test          # 단위 테스트
npm run build     # dist/ 에 정적 파일 생성
```

실제 엑셀 파일로 가져오기 결과 확인: `XLSX=/경로/가계부.xlsx npx vitest run scripts/`

## 알려진 한계 / 다음 단계
- 두 사람이 각자 휴대폰에서 쓰면 데이터가 따로 저장됩니다 → 지금은 백업 파일로 옮기고, 다음 단계로 클라우드 동기화(Supabase 등) 추가 예정.
- 할부 관리, 반복 지출 자동 등록, 연간 이벤트(자동차세) 알림, 카드 명세서 CSV 가져오기는 2차 범위.
