# 메덩파카 가계부

엑셀 가계부(수입 · 지출계획 · 지출 · 피벗 시트)를 옮긴 모바일 웹앱(PWA)입니다.
데이터는 **이 브라우저(localStorage)에만** 저장되고 외부로 전송되지 않습니다.

## 기능

| 화면 | 엑셀에서 하던 일 |
|---|---|
| 요약 | 잔액 카드, 큰 항목별 원형 진행, 최근 지출, 할부 현황(회차·남은 금액), 실수입/실지출, 실수입−실지출, 예상 월말 잔액(남은 고정비·저축 차감), 계획 단계 적자 경고, 그룹별 진행률, 예산 초과 항목 |
| 지출 | 이번 달 반복 항목 한 번에 등록(금액 수정·건너뛰기), `2026년 11월 지출` 표 입력. 큰 항목 → 작은 항목 연동, 주차 자동 계산(1–7일=1주차), 내용 자동완성(이전 분류·결제방법 채움), 수정/삭제, 필터 |
| 수입 | 수입 계획 + 실 수입 내역, 전월 잔액을 이월금으로 추가 |
| 예산 | 그룹·항목별 계획/실지출/차이, 전월 예산 복사, 헌금 계산(사람별 십일조 + 공동 기타 헌금 합계를 헌금 예산에 적용), 피드백 메모 |
| 리포트 | 일별 지출 막대 차트(지출 전체/생활비/저축), 항목 타일, 항목×주차(`지출 합계` 피벗), 큰 항목×주차, 결제방법×큰 항목(`결제방법` 피벗), 항목별 순위, 최근 6개월 |
| 공통 | 화면 맨 위에서 아래로 당기면 동기화(당겨서 동기화) |
| 설정 | 계절 배경(보고 있는 달 기준, 켜기/끄기), 할부 등록(원금·기간·수수료 → 매달 할부금 자동 계산), 반복 지출·수입 관리(매달/특정 월, 지난달 고정비에서 가져오기), 화면 테마(기기 설정/라이트/다크 × 6가지 색상), **엑셀(.xlsx) 가져오기**, JSON 백업/복원, 십일조 규칙, 분류·결제방법 관리 |

### 엑셀 가져오기
시트 이름이 아니라 머리글로 표를 찾으므로 매달 시트 이름이 바뀌어도 됩니다.
- 지출: `날짜 / 큰 항목 / 작은 항목 / 결제방법 / 내용 / 금액 / 비고`
- 실 수입: `날짜 / 내용 / 금액`, 수입 계획: `이번 달 수입 계획` 블록
- 지출 계획: `이번 달 ○○ 계획` 블록들, 분류: `지출 목록` 시트
- 금액은 원 단위로 반올림합니다 (예: 헌금 395,906.7 → 395,907).
- "해당 월 교체"를 켜면 같은 달을 다시 가져와도 중복되지 않습니다.

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm test          # 단위 테스트
npm run build     # dist/ 에 정적 파일 생성
```

실제 엑셀 파일로 가져오기 결과 확인: `XLSX=/경로/가계부.xlsx npx vitest run scripts/`

## 함께 쓰기 (Supabase 동기화, 종단간 암호화)
설정 → **함께 쓰기**에서 이메일로 로그인하고 가계부를 만들거나 초대받아 참여합니다.
가계부 내용은 기기에서 가계부 비밀번호로 암호화된 뒤 올라가며, 서버에는 암호문만 저장됩니다.
서버 연결 방법은 [`supabase/README.md`](./supabase/README.md)를 보세요. 연결 전에는 지금처럼 이 기기에만 저장됩니다.
